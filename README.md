# Spring Security Project

This is a hands-on Spring Security project demonstrating:

## Features
- User authentication & authorization
- JWT based security
- Role-based access control
- Secure REST APIs

## Tech Stack
- Java
- Spring Boot
- Spring Security
- JWT
- MySQL / H2

## How to Run
1. Clone the repository
2. Update application.properties
3. Run the application

## Learning Outcome
- Understood Spring Security filters
- Implemented JWT authentication
- Secured REST APIs
